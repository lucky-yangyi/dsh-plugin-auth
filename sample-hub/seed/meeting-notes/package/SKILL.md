# Meeting Notes（演示市场技能）

示例技能包，用于验证技能市场的搜索与安装功能。

## 工作流程
1. 接收原始转写或要点。
2. 归并为 议题 / 决议 / 待办（带负责人与截止时间）。
3. 输出 Markdown 纪要，可直接粘贴进文档。
