## 1. 这是什么

智能工作台是一个**在浏览器里使用的 AI 助手平台**：你可以像聊天一样向 AI 提需求，也可以把 Word、Excel、PPT、PDF、图片等资料交给它，让它帮你读文件、写方案、做分析、起草报告。

它和普通聊天工具的关键区别：

| 能力          | 说明                                             |
| ----------- | ---------------------------------------------- |
| **每人独立账号**  | 账号由管理员统一开通；你只能看到自己的会话、文件和资料，看不到他人的             |
| **能读你的资料**  | 支持上传单个文件、**整个文件夹**，以及**压缩包（ZIP）自动展开**          |
| **在线预览**    | Word / Excel / PPT / PDF / 图片可直接在网页里打开预览，不用先下载 |
| **可选模型**    | 默认按任务难度自动选模型；也可以手动指定某个模型                       |
| **技能与技能市场** | 可安装"技能"扩展 AI 的能力（如特定格式的处理流程）                   |
| **手机也能用**   | 手机浏览器打开同一地址即可使用，界面自动适配                         |

> ⚠️ 提醒：AI 生成的内容可能存在不准确之处，**重要结论请务必人工复核**后再对外使用。

## 2. 开始使用

### 2.1 打开与登录

1. 用浏览器打开工作台地址（由管理员提供，形如 `http://……:3080/app`）。
2. 输入**账号**和**密码**后点「登录」。

**账号规则**

- 账号是**你的 11 位手机号**（由管理员统一导入开通）。
- 系统会自动忽略粘贴时带入的空格、横线等符号；但如果格式不是手机号，会提示「账号必须是 11 位手机号」。
- **不支持自助注册**。若页面上没有注册入口，或提示"账号由管理员统一导入"，请联系管理员开通。
- 密码长度 8–128 位；连续输错会有短暂延迟（防暴力破解），属正常现象。

### 2.2 修改密码 / 退出

- **修改密码**：登录后，在界面中找到「修改密码」入口，输入原密码与新密码确认。
- **退出**：点「退出登录」。退出后本地不再保留登录状态，**在公用电脑上请务必退出**。

> 忘记密码：目前没有自助找回功能，请联系管理员重置。

## 3. 会话：你的工作抽屉

一次「会话」就是和 AI 围绕某个主题的一轮完整讨论（含所有提问、回答、上传的文件）。左侧栏是你的会话列表。

### 3.1 新建会话

点侧栏的「**新建会话**」，即可开始一个全新话题。

> 建议：每换一个项目/主题就新建一个会话。会话之间互不干扰，也便于以后回看。

### 3.2 切换与查看历史

- 在侧栏点某个会话即可切换过去，历史对话内容会完整保留。
- 已经问过的问题、上传过的文件，随时可以翻回去查看。

### 3.3 删除会话

不需要的会话可以删除（删除后该会话的对话与文件一并移除，**不可恢复**，请谨慎）。

## 4. 与 AI 对话

### 4.1 提问

在底部输入框输入你的需求，按「发送」（或回车发送）。

**几个让结果更好的写法：**

- 说清**用途和对象**：例："帮我起草一份给院领导的汇报，约 800 字，语气正式"。
- 说清**依据**：已经上传了资料时，指明"按我上传的《××招标文件》来写"。
- 分步骤提要求：先要提纲，确认后再让它展开写，比一次性要长文更可控。

### 4.2 执行过程

AI 在思考和调用工具时，界面会显示可展开的**执行步骤**（如读取了哪个文件、做了什么处理）。点击可展开查看细节。

- **本轮计时**：进行中显示计时，结束后显示本轮用时。
- **中途停止**：AI 正在回答时会出现「停止」按钮，点它可中断当前这一轮。

### 4.3 出错怎么办

如果这一轮执行失败，对话里会直接出现**红色错误卡片**说明原因（例如密钥缺失、文件格式不支持等）。按卡片提示处理即可；若反复失败，把错误内容截图发给管理员。

## 5. 上传资料（文件 / 文件夹 / 压缩包）

这是工作台最常用的能力之一。

### 5.1 三种上传方式

1. **拖拽**：把文件直接拖到页面上的拖拽区域。
2. **选文件**：点上传按钮，选择单个或多个文件。
3. **传整个文件夹**：用「上传目录」选择文件夹，系统会把整个目录结构（含子文件夹）一次性带上来 —— 适合提交成套的项目资料。

### 5.2 压缩包（ZIP）

直接上传 `.zip` 压缩包，系统会**自动解压**并按原有目录结构展开，不需要你先解压再一个个传。

**已知限制**

- 压缩包内**单个文件不超过 50 MB**，**解压后总量不超过 200 MB**，**条目数不超过 2000 个**。
- **加密压缩包**无法解压，请先解压后再上传。
- 文件名含中文一般不会有问题；极少数情况下乱码，改名后重传即可。

### 5.3 手机上传的特殊说明

- **iPhone / 安卓 Chrome、Firefox**：可以直接选择文件夹。
- **安卓微信内置浏览器**：不支持选择文件夹。解决办法：① 点右上角用「浏览器打开」（推荐 Chrome）；② 或把资料压成 ZIP 后上传。

## 6. 文件面板与预览

界面右侧是**文件面板**，以树形结构展示你在本会话中上传的全部文件。

- **点击文件**即可在线预览（Word / Excel / PPT / PDF / 图片等）。
- Office 文档由服务端转换成可预览格式，预览时右栏会自动变宽。
- 可**下载**、**删除**已上传的文件。
- 文件面板可**折叠收起**，需要更大对话区域时收起它。

> 转换需要一点时间（默认单个转换超时为 60 秒），同时进行的转换数量有限（默认 2 个），批量预览请稍候。

## 7. 选择模型

顶栏有**模型选择器**，两种模式：

- **自动（推荐）**：系统按任务类型自动选模型。例如涉及"图片/截图/识图/OCR"会自动走视觉模型；涉及"代码/报告/方案/分析/标书/论文"等复杂任务会自动走更强的模型。
- **手动指定**：你想固定用某个模型时，在下拉里直接选。选定后**当前会话**以手动选择为准；想恢复自动，选回「自动」即可。

> 可选模型包括内置的 DeepSeek 系列，以及管理员接入的其他厂商模型（如已配置的通义千问等）。

## 8. 技能与技能市场

**技能**是一组预设的工作方法，能让 AI 按固定流程完成某类任务。

### 8.1 使用已有技能

在输入框输入 **`/`**，会弹出技能菜单，选择某个技能即可调用（例如 `/某技能名 `）。

### 8.2 安装 / 卸载技能

打开**技能市场**，可以：

- **搜索**需要的技能；
- **安装**：安装后即可在 `/` 菜单中使用；
- **卸载**：不再需要时可移除。

技能条目上会显示版本、作者等信息，便于判断来源。

## 9. 在手机上使用

用手机浏览器打开同一地址即可，界面会自动适配：

- 侧栏变成**左侧抽屉**，点顶部菜单按钮展开；
- 输入区做了防误触和底部安全区适配；
- 窄屏下文件面板默认收起，需要时通过头部按钮展开。

## 10. 常见问题

| 现象                | 原因与处理                                               |
| ----------------- | --------------------------------------------------- |
| 提示"排队中"/"任务较多"    | 同时使用的人较多，系统按上限排队（每人默认同时 2 个任务）。稍等后重试即可，这是保护机制，不是故障。 |
| 提示"账号必须是 11 位手机号" | 账号应填手机号；若粘贴时带了空格或符号，重新手输一遍。                         |
| 提示需要联系管理员开通       | 账号由管理员统一导入，不支持自助注册。                                 |
| 上传 ZIP 失败         | 检查是否加密、是否超过 50MB/200MB/2000 个条目的限制。                 |
| Office 文件预览不出来    | 转换需要时间，稍等或重试；若提示超时，文件可能过大或格式特殊，可转成 PDF 后重传。         |
| 选用某模型后调用报错（如缺少密钥） | 该模型尚未配置可用密钥，请改用其他模型，或联系管理员配置。                       |
| 看不到别人的会话          | 正常。每个账号只能访问自己的数据，这是数据隔离设计。                          |
| 手机微信里不能选文件夹       | 微信内置浏览器限制，请用系统浏览器打开，或改传 ZIP。                        |

## 11. 使用须知

1. **不要上传涉密或敏感个人信息**；对外发布前请复核 AI 生成内容。
2. **公用电脑用完请退出登录**。
3. 会话与文件**删除后不可恢复**，重要内容请先下载留存。
4. 遇到异常请把**页面截图 + 红色错误卡片内容**发给管理员，便于定位。
